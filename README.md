# TurnBattle - 回合制战斗游戏

## 项目概述
TurnBattle是一个基于Go和React开发的回合制战斗模拟游戏。玩家可以在游戏中体验策略性的回合制战斗，选择不同的角色和技能进行对战。

## 技术栈
- **服务端**: Go + WebSocket
- **客户端**: React + TypeScript
- **数据库**: PostgreSQL
- **部署**: Docker + Kubernetes

## 目录结构
```
.
├── server/          # Go服务端代码
├── client/          # React客户端代码
├── docs/            # 项目文档
├── templates/       # 模板文件
├── scripts/         # 脚本文件
└── README.md        # 项目说明
```
